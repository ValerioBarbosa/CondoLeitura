# CondoLeitura

**Leitura inteligente. Gestão eficiente.**

## Missão
Simplificar a gestão e a execução de leituras de água e gás em condomínios.

## Princípios
- Offline first.
- Menos cliques, mais produtividade.
- Uma tela, uma responsabilidade.
- Dados calculados não devem ser duplicados.
- Qualidade primeiro; funcionalidades depois.
